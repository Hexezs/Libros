Código QR y Cómo Agregar Libros

Código QR de esta página

Cuando subas esta página a GitHub Pages, este código QR apuntará automáticamente al link de tu biblioteca para que los alumnos lo escaneen con su celular.

1. Cómo agregar más libros en el HTML

Abre el archivo index.html con cualquier editor de texto o directamente en GitHub y busca <div id="catalogo-libros">. Copia y pega este bloque cuantas veces quieras: 

<article class="libro">
  <img class="portada" src="img/nuevo.jpg" alt="Portada">
  <span class="codigo">SIS-009</span>
  <span class="categoria">Redes</span>
  <h3 class="titulo">Nombre del Libro</h3>
  <p class="bibliografia">Autor (Año). Título. Editorial.</p>
</article>

2. ¿Dónde guardo las imágenes (.jpg o .png)?

Crea una carpeta llamada img junto a tu archivo index.html y sube ahí las portadas. Si todavía no tienes la foto de algún libro, la página generará automáticamente una portada digital con el título y código.
